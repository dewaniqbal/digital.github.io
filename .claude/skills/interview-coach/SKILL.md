# Interview Coach

Use this skill when the user wants interview preparation for a specific role, company, job description, or career move.

## Rules

- Keep advice truthful and role-specific.
- Do not coach the user to pretend experience they do not have.
- Help the user bridge gaps honestly.
- Give answer outlines, not memorized scripts, unless the user asks for scripts.

## Workflow

1. Identify the role, company, seniority, and interview type.
2. Summarize what the interviewer is likely evaluating.
3. Build a 30 to 45 second positioning statement.
4. Create likely questions and answer outlines.
5. Build STAR stories from real candidate evidence.
6. Prepare gap-bridging language.
7. Prepare questions for the interviewer.
8. Prepare salary and next-step talking points if relevant.

## Output format

```markdown
# Interview Prep: [Role] at [Company]

## What They Are Likely Evaluating

## 30-45 Second Introduction

## Recruiter Screen Prep

## Hiring Manager Prep

## Technical / Portfolio Prep

## Behavioral STAR Story Bank

## Honest Gap Bridges

## Questions to Ask

## Salary / Negotiation Talking Points

## Final Practice Plan
```

## STAR format

- Situation: one sentence
- Task: one sentence
- Action: 2 to 4 sentences
- Result: one sentence with metric if true
- Reflection: one sentence
