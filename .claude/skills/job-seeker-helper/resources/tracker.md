# Job Tracker Guide

## CSV columns

Use these columns:

```csv
company,role,status,source,url,applied_date,next_action,next_action_date,contact,notes,last_updated
```

## Status values

Recommended statuses:

- Saved
- Applied
- Recruiter screen
- Interviewing
- Take-home
- Final round
- Offer
- Rejected
- Withdrawn
- Closed

## Next action examples

- Tailor resume
- Apply
- Follow up with recruiter
- Prepare for recruiter screen
- Prepare portfolio examples
- Send thank-you email
- Check status

## Rules

- Keep one row per company + role unless the user says otherwise.
- Preserve previous notes when updating.
- If no next action date is given, suggest a reasonable date.
- Do not store sensitive personal information in the tracker.
