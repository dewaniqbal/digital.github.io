# End-to-End Workflow

## 1. Intake

Collect or infer:

- candidate resume/CV
- target job description
- role title and company
- target location and work style
- seniority level
- tone preference
- deadline or urgency

If something is missing, proceed with best effort and mark assumptions.

## 2. Decode the job description

Create a plain-language summary:

- role purpose
- must-have skills
- nice-to-have skills
- tools and technologies
- soft skills
- industry/domain terms
- likely business outcomes

## 3. Build the role-match matrix

Use this structure:

| Job requirement | Candidate evidence | Strength | Resume action |
|---|---|---:|---|
| SQL | Built weekly sales queries | Strong | Put SQL in summary and first role bullets |
| A/B testing | Basic marketing campaign analysis | Medium | Say "experiment analysis exposure" only if true |
| Power BI | No evidence | Gap | Do not claim; mention Tableau if relevant |

## 4. Tailor the resume

- Keep all factual history intact.
- Put the most relevant proof near the top.
- Add job-description language only when it accurately describes the candidate's real experience.
- Improve bullet structure: action + scope + method/tool + result.
- Use placeholders for missing metrics.

## 5. Write job-specific outreach

Make the cover letter and recruiter message specific to the role. Avoid generic openings like "I am writing to express my interest." Use concrete match points.

## 6. Prepare interviews

Prepare for:

- recruiter screen
- hiring manager interview
- technical or portfolio interview
- behavioral interview
- salary discussion

## 7. Track actions

Create or update `job_tracker.csv` with:

- company
- role
- status
- source
- URL
- applied date
- next action
- next action date
- contact
- notes
- last updated

## 8. Final quality check

Before final output:

- Remove unsupported claims.
- Mark assumptions.
- Check spelling of company, role, and tools.
- Ask the user to verify all dates, metrics, and sensitive information.
