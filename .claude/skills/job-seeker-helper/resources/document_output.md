# Document Output Guide

## Markdown-first outputs

Default to clean Markdown because it is easy to review, copy, and convert.

Use these files:

- `ats_keyword_audit.md`
- `tailored_resume.md`
- `cover_letter.md`
- `recruiter_message.md`
- `interview_prep_pack.md`
- `follow_up_email.md`
- `application_packet.md`

Use `job_tracker.csv` for the tracker.

## Formatting rules

- Use clear headings.
- Keep paragraphs short.
- Use bullets for scannability.
- Avoid tables inside the final resume unless the user asks.
- Use placeholders where facts must be verified.

## DOCX/PDF fallback

If document creation tools are available, Claude may create polished `.docx` and PDF versions after the Markdown drafts are approved. If document tools are unavailable, provide Markdown and CSV only.

## Verification note

Always end final application drafts with a short reminder:

```text
Please verify all dates, metrics, company names, tools, and personal information before submitting.
```
