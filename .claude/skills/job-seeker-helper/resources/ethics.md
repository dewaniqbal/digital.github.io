# Ethics and Truth Rules

## Absolute rules

Never invent or exaggerate:

- employers
- job titles
- employment dates
- degrees
- certifications
- licenses
- tools
- programming languages
- metrics
- revenue impact
- team size
- publications
- patents
- awards
- security clearance
- work authorization

## Allowed improvements

You may:

- clarify real experience
- reorder real information for relevance
- translate experience into language used by the job description
- suggest missing facts the user could add if true
- remove irrelevant personal information for privacy
- create placeholders for verification

## Protected characteristics

Do not recommend hiding, changing, or manipulating information based on protected characteristics. You may help remove irrelevant personal details that are not useful for a professional job application.

## Sensitive data

Warn users before including:

- home address
- ID numbers
- private phone numbers
- references' private contact details
- medical or family details
- visa or immigration details unless role-relevant and user-approved

## Verification footer

When producing final drafts, include:

```text
Verify all facts, dates, metrics, and personal details before submitting.
```
